# Battlebot Workshop & Arena 01 Prototype

제공된 GLB 부품으로 로봇을 자유 조립하고 즉시 테스트 주행 또는 AI 전투를 할 수 있는 브라우저용 3D 프로토타입입니다.

## Arena 01 메인 로비

- 시작 화면은 16:9 가로 모바일 기준 Arena 01 로비이며 별도 차고 배경을 만들지 않고 실제 경기장·관중석·펜스·바닥을 그대로 사용
- 마지막으로 저장한 `battlebot-workshop-assembly-v9` 블록 그래프를 읽어 플레이어 로봇 한 대만 중앙 오른쪽에 전시. AI 전투·주행 물리는 로비에서 정지
- 낮고 가까운 전면 3/4 전용 카메라, 미세한 자동 오빗, 따뜻한 상부 키 라이트·차가운 필·붉은 림 라이트로 검은 차체 윤곽을 강조
- 상단 프로필/랭크/재화/친구/우편/설정, 왼쪽 `커리어 | 로봇 제작 | 상점 | 이벤트`, 오른쪽 시즌/일일 보상/초보자 미션을 분리 배치
- 빠른 전투 버튼은 없으며 왼쪽 하단의 큰 `FIGHT!` 버튼 하나만 전투 진입점으로 사용. 전투 모드와 아군 피해를 고른 뒤 짧은 UI 음향·암전과 함께 Arena 01로 전환
- `아이콘.png` 원본 그림을 단일 CSS 스프라이트로 사용하며 원본에 포함된 한글 라벨 영역은 노출하지 않음. 메뉴 이름과 설명은 실제 HTML 텍스트로 별도 렌더링
- 모든 로비 버튼은 hover/press 피드백과 클릭 음향을 제공. 구현되지 않은 메뉴도 무반응 버튼이 아니라 해당 정보 패널을 열며, 로봇 제작은 실제 3D 작업장으로 이동
- 작업장 하단 `메인화면` 또는 전투 중 `Esc`로 로비 복귀. 복귀할 때 저장 데이터를 다시 읽어 전시 로봇을 즉시 동기화
- 첨부 레퍼런스의 16:9 비율을 기준으로 1280×720에서 프로필 462×70, 왼쪽 메뉴 326×76(4개 동일), 시즌 340×116, 보조카드 224×68(2개 동일), FIGHT 326×106으로 정렬
- 왼쪽 메뉴와 FIGHT의 좌우 경계를 정확히 일치시키고, 모든 패널의 둥근 캡슐 모양을 제거해 오른쪽 사선·얇은 외곽선·짙은 남색 반투명 패널로 통일
- 1050px 이하와 760px 이하 가로 화면에는 별도의 축소 규칙을 적용해 프로필/재화/소셜, 메뉴, 시즌카드가 서로 겹치지 않게 유지

## 실행

이 폴더에서 로컬 HTTP 서버를 시작한 뒤 `index.html`을 엽니다.

```powershell
python -m http.server 8127 --bind 127.0.0.1
```

브라우저 주소: `http://127.0.0.1:8127/`

Three.js 모듈은 jsDelivr에서 로딩되므로 최초 실행 시 인터넷 연결이 필요합니다.

## 자유 조립 작업장

### Lv.1 소형 Grid 블록 모드

- `GRID_UNIT = 0.36`으로 통일해 중형 로봇 폭 2.88m에 기본 큐브가 정확히 8개 들어간다. 큐브 0.36m, 1×2 0.72m, 1×3 1.08m, 반높이 평판 0.18m로 정확히 비례한다.
- 완성 차체 데이터·Mesh·HP·거대 Collider를 실행 구조에서 제거했다. 새 설계는 `Core + 플레이어 블록 + 기능 부품`뿐이며 블록/부품 모드 전환 중에도 같은 구조가 그대로 보인다.
- 카탈로그를 누르면 설치 도구만 선택되고 블록 수는 변하지 않는다. 플레이어가 기존 블록의 위·아래·왼쪽·오른쪽·앞·뒤 면을 직접 가리켰을 때만 해당 Face Normal 옆 Grid Cell에 반투명 프리뷰가 나타난다.
- 클릭·터치하면 그 위치에 설치되며 같은 도구가 계속 유지된다. 마우스를 누른 채 면을 따라 드래그하면 여러 블록을 연속 배치하고, 이미 점유된 Cell은 중복 생성하지 않는다.
- `R`은 현재 축으로 90도 회전하며 `X/Y/Z +90°` 버튼으로 회전축을 직접 바꿀 수 있다. 경사·코너 경사·긴 블록도 별도 방향 Mesh 없이 동일 데이터와 회전값을 사용한다.
- 삭제 모드에서는 원하는 블록 하나만 클릭/터치해 제거한다. Core는 보호되며 삭제 직후 연결 그래프를 다시 계산해 Core와 끊어진 덩어리를 경고한다.
- 빈 공간 드래그는 카메라 회전, 휠은 확대/축소다. 터치에서는 동일 PointerEvent 경로로 빈 공간 드래그와 두 손가락 핀치 줌을 처리한다.
- 블록마다 ID, 종류, Grid 위치, 90도 회전, HP, 질량, 방어력, 연결 강도, 레벨, 재질 티어를 독립 보존한다. 면 연결만 구조 연결로 인정하고 저장·불러오기 뒤에도 정확한 좌표와 회전을 복원한다.
- 공식 Lv.1 색상은 `#39afe7` 밝은 하늘색 금속이며, Box 계열은 Box Collider 메타데이터, 경사 계열은 단순 Convex Collider 메타데이터를 사용한다.

### 기능 부품 자유 배치 모드

- 실제 GLB 14종 사용: 기능 부품 11종 + Arena 01용 관중석, 낮은 철제 범퍼, 철제 보호 펜스. 완성 차체 GLB는 로딩 목록에 없다.
- 차체 선택과 고정 슬롯을 삭제했다. 바퀴·지지대·무기는 플레이어가 만든 어느 블록 면에든 직접 설치하고, 부착 대상 블록 ID를 저장한다.
- 부품을 마우스/터치로 직접 끌면 포인터 Raycast가 블록·기설치 부품의 실제 표면을 감지해 즉시 밀착
- 색상 기즈모로 X/Y/Z 추가 회전과 균등 크기 변경. 사용자 회전값은 표면 정렬 회전과 분리해 그대로 보존
- `이동 | 회전 | 크기 | 복제 | 삭제 | 되돌리기` 중심의 단순한 편집 UI
- 회전은 자유 드래그와 ±15°, ±45°, +90° 빠른 조절을 함께 지원
- 톱날, 바퀴, 지지대, 드럼/바 스피너 모두 위치·각도·크기·개수 제한 없음. 삭제된 망치/플리퍼는 카탈로그·전투·조작 UI에 나타나지 않는다.
- 실제 모델 Bounds의 접촉 방향 최저점을 MountSurface로 사용해 평면·경사·측면·뒤쪽 어디서도 관통 없이 4mm 이내로 밀착
- 스케일이나 회전이 바뀔 때 Bounds와 MountSurface를 즉시 다시 계산하므로 공중에 뜨거나 차체 안으로 파묻히지 않음
- 블록 → 지지대 → 무기처럼 부품끼리 이어 붙일 수 있으며, 대상 부품의 실제 메시 표면도 Raycast 대상에 포함
- 연결 가능한 표면이 없으면 프리뷰의 마지막 정상 부착 상태를 유지하고 설치 확정을 허용하지 않음
- 선택한 바퀴는 `바깥면 뒤집기`로 허브를 정상 회전 180° 반전. Negative Scale은 사용하지 않음
- 한쪽 바퀴가 있는 축의 반대편 블록 면에 바퀴를 설치하면 같은 높이·같은 전후 위치·평행 회전축을 공유하는 Mirror Alignment를 적용한다. 좌우 허브는 각각 바깥을 향하며 플레이어가 선택한 좌우 위치는 유지한다.
- `무기 전체 제거`는 확인창을 거친 뒤 차체와 바퀴만 남기며, 바로 되돌리기 가능
- 조립 데이터는 Grid 블록 그래프와 표면 점·Surface Normal·대상 블록 ID·축 연결을 포함한 `localStorage` 버전 9 스키마로 저장한다. v7/v8의 완성 차체 장착 기록은 구조에서 제거하고 Core 기반 데이터로 이전한다.
- 모바일 폭에서는 선택한 부품 편집 시 카탈로그가 접혀 3D 드래그 공간을 확보

## 선택형 축 맞추기

자동 방향 보정과 강제 스냅은 없습니다. 범용 지지대에서 사용자가 `축 맞추기`를 누른 경우에만 가장 가까운 두 지지대를 한 쌍으로 정렬합니다.

- 왼쪽 구멍은 오른쪽/안쪽, 오른쪽 구멍은 왼쪽/안쪽을 향함
- 두 구멍 높이와 중심선 오차를 0으로 맞춤
- 가운데 회전 무기 장착 공간 유지
- 위치 복사나 Negative Scale 대신 오른쪽 지지대를 로컬 Y축 180° 회전
- 버튼을 누르지 않으면 같은 방향, 대각선, 수평/수직 등 사용자가 만든 상태를 그대로 유지

## 표면 및 연결 축 우선순위

- 일반 지지대/부품: 포인터 Raycast 접점 + 실제 Surface Normal + 회전된 Bounds로 MountSurface 계산
- 평평한 중앙: 부품 기본 장착면과 차체가 평행하게 정렬
- 경사진 앞·뒤: 차체 경사 Normal을 기본 방향으로 사용하고 추가 회전은 그 위에 합성
- 측면: Local +Y 장착 방향을 측면 Normal로 돌려 밑판이 측면에 밀착
- 톱날 중앙 구멍, 드럼 양쪽 축, 바 스피너 고정축: 일반 표면보다 호환 지지대의 축 중심 스냅을 우선
- 바퀴: 가리킨 블록 면의 Surface Normal을 로컬 회전축에 맞춰 직접 장착. 고정 슬롯 없음

## 로컬 축 규칙

- 차량 물리 루트: `+Z 전방`, `-Z 후방`, `-X 왼쪽`, `+X 오른쪽`, `+Y 위`
- 톱날과 바 스피너는 설치 회전이 적용된 루트 아래 로컬 Y축 피벗으로 회전
- 드럼 스피너는 설치 회전이 적용된 루트 아래 로컬 X축 피벗으로 회전
- 무기를 세로, 수평, 측면, 45°로 배치해도 월드축이 아니라 설치된 부품의 로컬축을 따라 작동

## 주행·전투 조작

- `W` / 조이스틱 위: 차량이 바라보는 Local +Z 방향으로 전진
- `S` / 조이스틱 아래: 후진
- `A` / 조이스틱 왼쪽: 좌회전
- `D` / 조이스틱 오른쪽: 우회전
- `Shift`: 브레이크
- `E`: 설치된 모든 톱날·바·드럼 스피너 동시 ON/OFF. 같은 톱날을 2개 이상 달아도 모든 인스턴스가 각각 가속·회전·충돌 판정
- `T` 또는 모바일 `SELF RIGHT`: 완전히 뒤집히거나 옆으로 누운 로봇을 0.72초 동안 **현재 X/Z 위치 그대로** 자세만 복구
- `R`: 전투 재시작
- `V` 또는 상단 `ARENA TOP`: 일반 전투 카메라와 경기장 전체 수직 탑뷰 전환
- `C` 또는 `COLLIDERS`: 활성 블록별 Compound Collider, 바퀴 Collider, 빨간 Center of Mass 디버그 표시
- `Esc`: 메인 로비 복귀. 상단 `작업장` 버튼은 바로 3D 작업장으로 이동
- 음량·그래픽·30/45/60 FPS·대시 키 설정은 전투 중 우측 상단 일시정지 버튼 안에서 조절하며 새로고침 후에도 유지한다.
- 점령전 QA는 3무기 7시나리오×20회, 피격 후 전·후진 복구 5시나리오×20회, AI 10대 100m 직선 주행, 2v2/4v4/10v10 성능 비교와 5분 10v10 행동 검사를 제공한다.

## 전투 피드백과 환경

- 개인전, 2v2, 3v3, 4v4, 6v6, 8v8을 선택할 수 있고 팀전의 아군 피해는 기본 OFF. 적 닉네임은 빨강, 아군은 파랑으로 표시하며 먼 거리·산업맵 장애물 뒤 이름표는 숨긴다.
- AI는 `SEARCH/CHASE/ATTACK/RETREAT/FLANK/AMBUSH/REENTRY/RECOVER` 상태와 `Aggressive/Defensive/Flanker/Chaser/Brawler` 성향을 사용한다. 저체력 후퇴, 엄폐 방향 이탈, 측후방 우회, 교전 중인 적 뒤치기, Hit-and-Run 재진입을 성향별로 다르게 수행한다.
- 플레이어와 톱·드럼·바 스피너 AI가 같은 조립/파괴 경로 사용
- 실제 Contact Point, 공격/상대 속도, 무기 끝단의 `AngularVelocity × Radius`, 무기·차량 질량, 충돌 방향, 무게중심 레버암으로 ImpactScore와 Force/Torque를 계산
- 강한 바 스피너는 큰 수평 임펄스와 접촉점 토크를 사용하고, 큰 상승력은 하부를 정확히 건드린 드럼에만 허용한다.
- 독립 충돌 순간 한 번의 대형 임펄스와 토크만 적용한 뒤 위치·회전을 강제하지 않음. 같은 회전 무기 접촉이 이어질 때 피해와 작은 스파크는 반복되지만 차량 발사 힘은 최초의 2.5~4%로 제한. 0.5초 이상 실제로 분리되고 지면에 닿은 상대만 새 독립 강타가 되며, 한 대상은 0.45초 안에 여러 무기에서 완전 발사 힘을 중복으로 받지 않음
- 상승 중 중력 1.18배, 하강 중 1.85배와 최대 하강 속도 38m/s를 적용해 멀리 튕겨도 오래 떠 있지 않음
- Swept 지면 교차 검사로 고속 낙하를 잡고, 착지점 레버암에서 단 한 번의 작은 회전 임펄스를 계산. 낮은 Bounciness와 접촉 충격 에너지 손실 뒤 남은 관성만 유지하며 착지 후 매 프레임 추가 충격 토크를 넣지 않음
- 모든 활성 블록과 기능 부품의 질량 중심을 로봇 루트 로컬 좌표로 환산해 한쪽 무거운 무기는 COM을 실제 방향으로 이동시킨다.
- AI는 전복 상태가 지속되면 스폰으로 순간이동하지 않고 그때의 X/Z를 유지한 채 제한된 자세 복구를 수행하고 즉시 점령/교전/회복 행동으로 재진입한다.

- 장애물 회피 그래프는 87개 노드와 224개 링크로 구성되며 모든 87개 노드가 하나의 연결망이다. 직접 시야 경로와 0.45초 재탐색을 함께 사용한다.

- 중간 속도 바퀴 로봇으로 z=-190에서 z=190까지 중앙 직선을 실제 생산 물리로 달린 결과는 15.82초였다. 전 구역 자동 순회도 8개 지점을 모두 통과했다.

## V96 전수 감사 보완

- 치명타의 주변 피해 상한을 고정 110에서 실제 ImpactEnergy 기반 110~180 범위로 변경했다. 장갑과 연결강도 저항을 함께 계산하므로 약한 치명타는 주 타격 블록만, 충분히 강한 치명타는 가까운 저HP 블록 여러 개와 Core 연결이 끊긴 덩어리를 함께 분리할 수 있다.
- 블록 파괴 순서는 `원색 소파편 → 금속 스파크 → 원본 블록 분리`로 생산 경로와 QA 경로를 통일했다. 하늘색과 노란색 치명타 전용 검증 버튼을 제공한다.
- AI의 `SEARCH`는 적이 없을 때 정지하지 않고 장애물 회피 탐색 주행을 한다. 후퇴가 끝나면 1.55초 동안 `REENTRY` 상태를 유지하고, 교전 중인 적의 후방을 노리는 `AMBUSH`와 성향별 위험/약한 적/팀 지원 우선순위를 사용한다.
- `?systemsQA=1&qa=isolated`에는 SEARCH/CHASE/ATTACK/RETREAT/FLANK/AMBUSH/REENTRY, 플레이어·AI 현재 위치 자세 복구, AI·플레이어 리스폰, Spawn Protection 피격 차단을 실제 생산 업데이트로 검사하는 버튼이 있다.
- `?blockCombatQA=1&qa=isolated`에는 하늘색/노란색 치명타, 다중 블록 분리, 원색 파편/원본 Material 유지, 3~6초 소파편과 6초 블록 파편 제거 검사가 있다.
- `?blockQA=1`에는 20블록 연속 배치, 모든 Lv.1 블록 X/Y/Z +90도 회전, 좌우 바퀴 평행 미러 정렬 검사가 있다.

## V97 지면·장애물 물리 수정

- 시각 타일과 물리 바닥을 분리하고 Industrial 물리 바닥을 상단 Y=0, 두께 1.2m인 단일 Static Box로 구성했다. 생산 물리는 90Hz 서브스텝과 Swept 지면 교차 뒤 최종 침투 검사를 한 번 더 수행하며, 침투 시 X/Z·회전은 건드리지 않고 계산된 Y 오차만 보정한다.
- 바퀴 접지는 `PhysicsFloor`만 대상으로 한다. 장애물·같은 로봇 블록·바퀴·무기에는 서스펜션/구동 접지를 만들지 않는다.
- 차량 전체의 과대 원형 Collider를 장애물 판정에서 제거했다. 현재 활성 블록 Compound Collider와 바퀴의 실제 2D 외곽을 만들고, 컨테이너/방벽의 회전된 GLB Bounds OBB와 SAT로 접촉한다.
- 장애물 충돌 시 별도의 공격 임펄스·폭발·수직 힘을 추가하지 않는다. 충돌 Normal 속도만 0.018~0.025 Restitution으로 해소하고 접선 속도는 표면 마찰로 감쇠하며 Contact Point 레버암에서 작은 Yaw만 계산한다.
- 컨테이너·방벽·펜스는 비균등 최종 Y 스케일로 바닥을 다시 계산해 6mm만 바닥에 매입했다. 특히 높이를 0.48배로 낮춘 콘크리트 방벽이 이전 Uniform Scale 높이 때문에 떠 있던 문제를 제거했다.
- `COLLIDERS`는 차량뿐 아니라 단일 물리 바닥, 26개 컨테이너, 30개 방벽, 4개 외곽 펜스 경계도 표시한다. `?map=industrial01&physicsQA=1`의 버튼은 정립/측면/전복 낙하와 방벽 3/9/24m/s, 컨테이너 12m/s 충돌을 생산 `Robot.updatePhysics`로 재현한다.
